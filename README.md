# RASEEN Website — Version 2.2

A bilingual Arabic/English multi-page static website designed for GitHub Pages.

## Files
- `index.html` — home page
- `about.html`, `services.html`, `sectors.html`, `approach.html`, `insights.html`
- Individual sector pages such as `sector-real-estate.html`, `sector-energy.html`, and others
- `market-entry.html` — pre-market entry assessment and high-level market orientations for Saudi Arabia, Morocco, and Ethiopia
- `market-study-portugal.html`, `market-study-morocco.html`, `market-study-ethiopia.html` — individual market study pages
- `privacy.html` — general privacy policy
- `inquiry.html` — inquiry form
- `style.css`, `script.js`, `.nojekyll`

## Publish/update on GitHub Pages
Upload the *contents* of this folder to the repository root (so `index.html` is directly in the repository root), then commit the changes. Keep the current repository backup ZIP before replacing files.

In GitHub, open **Settings → Pages** and verify deployment from branch `main`, folder `/(root)`.

## Before launch
1. In `inquiry.html`, replace `YOUR_EMAIL@example.com` with the real business email.
2. Review the privacy policy with a qualified legal professional and align it with the actual data-handling process and any tools used by the site.
3. Verify the live site, mobile layout, images, bilingual switching, and links after publishing.

The website uses external Google Fonts and Unsplash images, so those resources require an internet connection.



## Images and final checks
The site uses externally hosted Unsplash photographs. Confirm image loading and current provider terms during pre-publication testing. The site pages do not display photo-credit labels.

   - ملاحظة: صورة حقيقية ذات هوية سعودية واضحة، ولا يظهر فيها أشخاص. وهي تُظهر سيارة الإسعاف في موقع مفتوح، لا واجهة مستشفى.

2. **الطاقة، الغذاء، الصناعة، التقنية، البنية التحتية، العقار، والقطاعات المتنوعة**
   - المصدر: صور Unsplash المستضافة على images.unsplash.com، وتظهر روابطها المباشرة في صفحات HTML.
   - الترخيص العام: https://unsplash.com/license — يجيز الاستخدام المجاني التجاري وغير التجاري، مع الاستثناءات الموضحة في شروط Unsplash.

**تنبيه تدقيق:** لا يُعد هذا السجل ضمانًا قانونيًا مطلقًا؛ تراخيص الصور قد لا تغطي العلامات التجارية أو حقوق الملكية/المعالم الظاهرة في الصورة. تم توثيق مصدر وترخيص صورة الإسعاف تحديدًا، وترخيص Unsplash العام لبقية صور Unsplash.
